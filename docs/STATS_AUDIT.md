# Statistics audit and implementation checkpoint

Status: staging migration and real API/browser acceptance completed; production rollout underway. The failed initial connector attempts and test-fixture failures are resolved as recorded in IMPLEMENTATION_PROGRESS.md.

## Source and architecture

Current main was cloned and all split JavaScript modules, prior progress/security records, tests, and live private RPC definitions were inspected. Private tables keep JSON league/season/schedule data, game state, revision/lease ownership and idempotent receipts. No database-generated player/team metrics or materialized stat views drive this client. Legacy public relations/views are outside the current RPC persistence path. Read-only schema inspection found private RLS enabled, no API-role private table grants, table/FK/status constraints, and management audit triggers. Code hashing and grant validation remain unchanged.

Definitions were checked against MLB's official glossary: [standard stats](https://www.mlb.com/glossary/standard-stats), [ERA](https://www.mlb.com/glossary/standard-stats/earned-run-average), [IP](https://www.mlb.com/glossary/standard-stats/innings-pitched), [WHIP](https://www.mlb.com/glossary/standard-stats/walks-and-hits-per-inning-pitched), [OBP](https://www.mlb.com/glossary/standard-stats/on-base-percentage), [SLG](https://www.mlb.com/glossary/standard-stats/slugging-percentage), [earned run](https://www.mlb.com/glossary/standard-stats/earned-run), and [RBI](https://www.mlb.com/glossary/standard-stats/runs-batted-in). Supabase's current changelog and [database functions](https://supabase.com/docs/guides/database/functions) documentation were consulted for RPC/privilege changes. Official rules' complete scorer reconstruction is **not** claimed for this app.

## Corrections, preservation and limits

The branch fixes hardcoded roster/series constraints, three-game import/format assumptions, ERA scaling, custom-rule workload aggregation, missing allowance counters, overtime automatic-player-run credit, direct ROE RBI credit, and team substitute omission. It rejects new tied completions, preserves legacy schedules rather than silently clinching them, and excludes duplicate IDs from player rebuilds. Rendering does not send a stats mutation.

No historical raw stats, credentials, sessions or league rows were changed by this work. No production backfill has run. Existing legacy aggregates may predate detailed game logs; the existing complete-coverage/import-match checks continue to gate rebuilding. Unknown historical allowance counts remain unavailable. Historical errors cannot be precisely rescored from box scores; ER/ERA are labeled estimates. A full chronological event ledger with scorer decisions is still needed for exact MLB earned-run reconstruction.

The roster model contains name strings and per-team/name stat keys, not independent player IDs. Transfer, reactivation and archive operations are unsupported; scored-season roster changes remain blocked. Substitutes explicitly replace a roster seat for a game and do not enlarge the lineup; global unassigned substitute names are not an active team's roster. Future archive/transfer support must preserve original game attribution and enforce capacity atomically.

Current simplified contact advancement and double-play prerequisites are retained; sacrifices, fielder's-choice categories, stolen-base statistics and advanced metrics are not invented. Manual corrections must maintain internal count consistency; manual corrections now check hit breakdown, earned runs and strikeouts against their totals, and rebuild corrected outs with the saved game rule; real browser correction persistence passes.
